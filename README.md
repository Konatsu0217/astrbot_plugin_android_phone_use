# Android 手机操控

**Android only · 仅支持 Android**

作者：Konatsu0217。为 AstrBot 提供打开手机应用、查看画面、点击、滑动、输入和返回等能力。

## 使用

需要兼容版本的 **AstrBot Android Launcher**，以及支持工具调用和图像输入的聊天模型。普通电脑或远程服务器上的 AstrBot 无法使用此插件操控手机。

1. Android 启动器已内置插件，启动 AstrBot 后自动准备，无需额外安装。独立安装版本通过 AstrBot 插件管理维护。
2. 在「工作台 → 手机操控」中选择模式，按界面引导完成授权，再打开总开关。
3. 由 AstrBot 管理员发起手机操控请求。

安装插件不会自动授予手机权限或开启操控。

## 限制与隐私

部分应用可能无法操作或截图；同一应用可能互相影响，操作也可能出错。无障碍模式会占用主屏，锁屏或熄屏时暂停。

截图和操作结果可能发送至你配置的模型服务，请避免展示密码、验证码等敏感信息。工具仅供 AstrBot 管理员调用；关闭手机操控总开关即结束会话，系统权限可在系统设置中撤销。
